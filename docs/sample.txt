The RAG Hallucination Guard system retrieves relevant text chunks using a FAISS vector index built from sentence-transformer embeddings. The guard's faithfulness threshold defaults to 0.6, meaning any generated answer scoring below that on the independent judge's faithfulness check is rejected rather than shown to the user. The judge is a second, separate LLM call that never sees the generator's reasoning, only the final answer and the same retrieved context chunks. This separation prevents the same model from simply rubber-stamping its own output. Every accepted answer includes citations back to the source chunk that supported it, giving full source traceability.
